## Publicar con GitHub Pages
1. Crea un repositorio público llamado `Web_Personal` (o el nombre que prefieras).
2. Sube todos los archivos manteniendo la estructura.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main` y carpeta `/root`.
4. Guarda y espera a que GitHub publique el sitio.

GitHub Pages sirve sitios estáticos directamente desde un repositorio. Para un sitio de usuario, el repositorio puede llamarse `<usuario>.github.io`; para un sitio de proyecto, la URL sigue el patrón `<usuario>.github.io/<repositorio>`.
